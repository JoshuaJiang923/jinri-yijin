# 今日一进

一个手机优先的个人推进工具原型，用来同时管理：

- 今日精力、睡眠和停止刷手机时间
- 60 分钟专注记录
- AI 商品广告的业务阶段和商家漏斗
- 工作项目的下一步与风险
- 学习、提示词和客户反馈
- 每周复盘

## 在线使用

HTTPS 地址：

<https://joshuajiang923.github.io/jinri-yijin/>

iPhone 使用 Safari 打开后，点“分享”→“添加到主屏幕”。在线地址只托管应用文件；个人记录保存在浏览器本地，不会上传到 GitHub。

## 启动

需要 Node.js。双击 `start.cmd`，或在当前目录运行：

```powershell
node serve.js
```

电脑打开 `http://localhost:4173`。

iPhone 与电脑连接同一个 Wi-Fi，在 Safari 中打开启动时显示的局域网地址，然后点分享按钮，选择“添加到主屏幕”。

## 数据

数据保存在浏览器的 `localStorage` 中，不会上传到服务器。更换手机、清理 Safari 数据或更换访问地址前，请在右上角设置里导出备份。

## 当前范围

- 单用户
- 无登录、无云端同步
- 手机优先，同时支持 Windows 浏览器
- 支持导出和导入 JSON 备份
- 不需要安装第三方依赖
